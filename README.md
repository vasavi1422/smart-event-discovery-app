# Smart Event Discovery App

A full-stack Smart Event Discovery application that helps users discover, explore, and manage events.

## Tech Stack
- Frontend: React
- Backend: Node.js
- Database: MongoDB

## Features
- User Authentication
- Event Discovery
- Event Management
- Responsive UI

## Installation

Frontend:
```bash
cd frontend
npm install
npm run dev
```

Backend:
```bash
cd backend
npm install
npm start
```
